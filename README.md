#### ⚙️ 模块一 // [ 神经中枢 • 后端矩阵 ] BACKEND & DAEMONS ENGINE
- **Базовый стек:** `Python 3.11+`, `FastAPI`, `Uvicorn ASGI`, `SQLite3 (WAL Mode: PRAGMA journal_mode=WAL)`, `Pydantic v2`.
- **Криптографическая защита:** `Argon2id` для хеширования паролей, `AES-256-GCM` для шифрования клиентских полезных нагрузок, `HMAC-SHA256` для проверки подлинности вебхуков.
- **Маршрутизаторы микросервиса (`routers/`):**
  - `auth.py` — авторизация, выдача JWT/Bearer сессий, генерация криптографических OTP.
  - `profile.py` — управление профилем, экспорт конфигов подписки, интеграция платёжного шлюза.
  - `client.py` — протокол синхронизации мобильных клиентов, валидация ключей доступа.
  - `admin.py` — панель супервизора, управление пулом нод, ручные оверрайды подписок, статистика.
- **Автономные фоновые демоны (`services/`):**
  - `billing_service.py` — непрерывный мониторинг сроков подписок, выставление grace-периодов, сверка транзакций.
  - `traffic_service.py` — потоковый сбор и агрегация сетевой телеметрии из системных журналов `journalctl` демона Hysteria 2.
  - `xray_service.py` — синтез динамических JSON-конфигураций Xray-core и балансировка входящих потоков.
  - `email_service.py` — асинхронный неблокирующий SMTP-диспетчер для кодов подтверждения и сигналов безопасности.
- **Платёжная интеграция:** ЮKassa API с валидацией цифровых подписей вебхуков и автоматической фискализацией кассовых чеков согласно 54-ФЗ и 422-ФЗ.

---

#### 📱 模块二 // [ 移动战术终端 • 安卓核心 ] ANDROID TACTICAL CLIENT
- **Базовый стек:** `Kotlin 2.x`, `Android SDK 35 (minSdk 24)`, `Jetpack Compose`, `Material Design 3`, `Coroutines & StateFlow`, `Tencent MMKV`, `OkHttp3 / Retrofit`, `WorkManager`, `Gradle Kotlin DSL`.
- **Двухуровневое ядро туннелирования:**
  - **`AndroidLibXrayLite` (Go / Go Mobile):** Скомпилированное в AAR ядро Xray-core v5 для гибкой маршрутизации VLESS/Trojan/Shadowsocks.
  - **`hev-socks5-tunnel` (C / CMake / Android NDK):** Ультраоптимизированный легковесный C-туннель для мгновенной трансляции IP-пакетов из системного `VpnService` в сокеты SOCKS5.
- **Архитектура UI:** Чистый MVVM-паттерн, реактивные киберпанк-интерфейсы, раздельное туннелирование по приложениям (Split Tunneling) и защищённый модуль самообновления с проверкой хэшей.

---

#### 🌐 模块三 // [ 全息神经矩阵 • 网页平台 ] CYBERNETIC WEB INTERFACES
- **Базовый стек:** `Modern HTML5`, `Tailwind CSS (Container Queries, Forms, Dark Mode)`, `Vanilla JS (ES6+ async/await)`, `Google Fonts (Inter, JetBrains Mono, Plus Jakarta Sans)`, `QRious`.
- **Интерфейсные узлы:**
  - **Landing Portal (`index.html`, `/android`, `/windows`, `/ios`):** Отзывчивый Mobile-First портал с неоновыми акцентами, анимацией стеклянных карточек (Glassmorphism) и быстрой загрузкой дистрибутивов.
  - **User Cabinet (`profile/auth`, `profile/`):** Личный терминал пользователя с мониторингом активного тарифа, таймером до истечения, прямой оплатой и динамическими QR-кодами для сопряжения устройств в один клик.
  - **Admin Command Deck (`admin/`):** Панель управления флотом серверов: пропускная способность нод, мониторинг нагрузки, аудит активности пользователей и потоковый просмотр системных логов.

---

#### 🖥️ 模块四 // [ 桌面中继单元 • 视窗系统 ] WINDOWS PROXY DECK
- **Базовый стек:** `Python 3.11+`, `CustomTkinter / Tkinter`, `WinINet API`.
- **Функционал:** Автоматическое управление системными параметрами прокси через реестр Windows, маршрутизация трафика без сторонних драйверов, фоновый супервизор локальных процессов.

---

#### 🌀 模块五 // [ 隐秘协议矩阵 • 量子穿透 ] PROTOCOLS & STEALTH MATRIX
- **VLESS + XTLS / Reality:** Имитирует легитимное TLS 1.3 рукопожатие к белым зарубежным сайтам, делая трафик абсолютно неотличимым от обычного веб-серфинга для систем глубокого анализа пакетов (DPI).
- **Hysteria 2 (QUIC / UDP):** Кастомный алгоритм контроля перегрузок на базе QUIC, обеспечивающий максимальную скорость даже при потере до 30% пакетов в нестабильных мобильных сетях.
- **Tun2Socks & HEV:** Перехват трафика на уровне ядра операционной системы, предотвращающий любые утечки DNS и IPv6.
